# STM32 舵机控制板

基于 STM32 微控制器的舵机控制系统，通过蓝牙模块（如 HC-05/HC-06）无线传输角度数据，实现对舵机的远程精准控制。

## 功能特性
- 📡 支持蓝牙无线通信，实时接收角度指令
- 🔧 基于 STM32 PWM 输出控制舵机转角
- 📐 角度范围：0° ~ 180°（可配置）
- ⚡ 响应速度快，控制精度高

## 硬件需求
- STM32F103 系列开发板
- HC-05 / HC-06 蓝牙模块
- 标准舵机（SG90 等）

## 使用方法
1. 烧录固件到 STM32
2. 配对蓝牙模块
3. 通过串口发送角度值（如 90），舵机转至对应角度

## 开发环境
- Keil MDK / STM32CubeIDE
- STM32 HAL 库

## 蓝牙串口调试APP推荐
- Serial Bluetooth Terminal（安卓蓝牙串口终端）（作者：Kai Morich）
- 专门用来和STM32+HC-05/06、ESP32等做无线串口收发，完全免费。
- 核心用途
- ✅ 替代USB串口，无线调试STM32/蓝牙模块（HC-05/06、HM-10等）
- ✅ 发指令（如 LED_ON\r\n ）、收日志，和你的串口代码完美匹配
- ✅ 支持经典蓝牙SPP（HC-05/06） 和BLE低功耗蓝牙（HM-10）
- ✅ 自带时间戳、自动换行、预设按钮、日志保存
